# GNR_602_Project
GNR_602_Project - Threshold an image using Kittler-Illingworth Optimum Threshold Selec- tion method, for single as well as multiple thresholds


Image Segmentation Tool Requirements
Dependencies
To run or develop this application, you'll need the following Python packages:
numpy>=1.20.0
opencv-python>=4.5.0
matplotlib>=3.3.0
scipy>=1.6.0
scikit-learn>=0.24.0
PyQt5>=5.15.0
Installation
For Users

Install Python: Download and install Python 3.8 or newer from python.org
Install Required Packages: Open a terminal or command prompt and run:
bashpip install numpy opencv-python matplotlib scipy scikit-learn PyQt5

Run the Application: Execute the Python script to start the application
bashpython image_segmentation_app.py


For Developers

Clone the repository (if applicable):
bashgit clone https://github.com/yourusername/image-segmentation-tool.git
cd image-segmentation-tool

Create a virtual environment (recommended):
bashpython -m venv venv

# On Windows
venv\Scripts\activate

# On macOS/Linux
source venv/bin/activate

Install dependencies:
bashpip install -r requirements.txt
